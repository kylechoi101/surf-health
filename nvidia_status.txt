Runtime guarantees (scripts/nim_worker.py):
  • Sandbox prefix allowlist (_BASH_ALLOW_PREFIXES, line 100): only
    git/gh/npm/npx/python/curl/grep/ls/cat/head/tail/sed/wc/echo/
    jq/dig and `cd web && / cd backend && / cd /Users/kylechoi/surf_health`
    prefixes are accepted. Anything else is denied at runtime.
  • Deny patterns (_BASH_DENY_RE): credentials, .env, secrets, rm -rf,
    sudo, ssh keys, npm publish, git config user.email.
  • In --no-write mode, all mutating git ops (commit, push, add, rm)
    are additionally blocked.
  • write_file refuses .env / credential paths in any mode.
  • SANDBOX DENY events are logged but do NOT count toward
    --max-bash-failures (so a chatty model doesn't burn the failure
    budget on probes).
  • _call_api auto-bumps timeout to 600s when base_url contains
    "11434" (covers both hybrid executor calls and single-backend
    Ollama calls — verified at scripts/nim_worker.py:416).
  • c6b9b5e adds a guard to refuse the worker re-invoking itself
    (the circular-self-invocation block).
