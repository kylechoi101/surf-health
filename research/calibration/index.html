Regime note— these holdout scores use days a lab sample was taken (fresh history). The public forecast is issued daily. Most days have a last lab result that is already several days old. That is a harder regime. See the methodology for how served-day performance is tracked.
AUCPR baseline— the persistence model (yesterday's result as today's prediction) scores 0.4815 at the county holdout level and 0.7913 at the beach holdout level in the current pipeline snapshot. The production model must clear that margin before promotion. These values are read live from the daily pipeline output. They were previously hardcoded at 0.172 / 0.241. That understated the baseline by roughly 3× and overstated the model margin over it.
