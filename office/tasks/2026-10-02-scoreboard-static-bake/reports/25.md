## Deviations

- Added `_backfill_persistence` in `lookup_serving.py`, which the brief did not list. `head_to_head` scores every column on the rows where all of them are present. History rows logged before today have no `p_exceed_persistence`, so without a backfill the same-rows subset would stay empty for every earlier served day. The first dry run showed this: `head_to_head` had no per-model entries. The backfill rebuilds the column for served-estimate rows from `beach_day`, as of each row's forecast date and using strictly prior labels. It only fills nulls, so it is idempotent.
- `compare_all_models.py` import order: the new import sits just before `app.ml.models`. Ruff passes.
