## Done
Extended `lib/staticData.ts`:
- `staticForecast(beaches, id, date)`: returns that beach's `forecast` only when `forecast.forecast_date === date`; otherwise null (also null for a null forecast, a missing beach or a null list).
- `beachDetail(id, options)`: fetches and parses `beach/{id}.json`, cached per session per id. The in-flight promise is shared. A failed, non-object or array result is not cached, so the next call retries.
- Section accessors: `staticObservations(id)`, `staticExplain(id, date)`, `staticHourly(id)`, `staticTides(id)`. Each returns null when the file is missing or the section is null or absent. `staticExplain` also returns null when `detail.forecast_date !== date`.
- `resetStaticCache()` now also clears the per-id detail cache.

Added 9 tests to `tests/static-data.test.mjs` (19 total): forecast date match and mismatch, detail hit and URL, detail 404 / error / non-object, once per id plus retry after failure, sections present, explain date mismatch, null or absent sections, and a missing detail file.
