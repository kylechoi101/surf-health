## Done
Wired `lib/api.ts` static-first for all eight getters. A small `staticFirst(path, load)` helper calls the static loader. On a non-null result it records a fresh entry in `lastServed` and returns the data. On null it calls the existing `request<T>(path)` unchanged. `API_BASE`, `request`, retries, `ApiError`, the cache helpers (`getLastFetchTime`, `wasServedFromCache`) and the offline cache are untouched.

Static source per getter:
- `getParentBeaches`: `parent_beaches.json` (array check)
- `getBeaches`: `beaches.json` via the session cache (`staticBeaches`)
- `getSystemHealth`: `health.json` (object check)
- `getObservations`: `beach/{id}.json` -> `observations`
- `getForecast`: `beaches.json[].forecast` via the session cache and `staticForecast` (date must match), with no second download
- `getExplanation`: `beach/{id}.json` -> `explain` (valid only when the file's `forecast_date` equals the date)
- `getHourly`: `beach/{id}.json` -> `hourly`
- `getTides`: `beach/{id}.json` -> `tides`
