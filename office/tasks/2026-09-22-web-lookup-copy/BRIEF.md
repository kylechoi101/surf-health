## Goal

The backend (surf-health PR 37) now SERVES a per-beach lookup estimate
instead of the daily ML probability. The number on every beach is now: the
share of that beach's lab tests over the past 12 months that exceeded the
safety limit, shrunk toward the statewide average (`p = (pos + 5·g)/(n + 5)`),
never Low if the last test exceeded, raised to High while a county advisory is
active. Bands keep the same cutpoints. Measured realized exceedance per band on
the served log: Low 3%, Moderate 11%, High 35%, Very High 82%. The ML still
trains but no longer sets the served number; it lost to the lookup on forward
lab outcomes (90-day AUROC 0.878 vs 0.824, AUC-PR 0.580 vs 0.395, Brier 0.060
vs 0.071, n = 11,616).

Update the web copy so no user-facing text claims the number is a machine
learning prediction of today's water. Copy only; no logic, data, or layout
changes. Repo is the worktree `/Users/kylechoi/shorelife-web-lookup` (branch
`feat/lookup-copy` from origin/main; `node_modules` is a symlink).
